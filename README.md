# TechBites

> 매주 한입씩 나누는 기술 이야기

TechBites는 각자 관심 있는 기술을 공부하고, 개인 블로그에 기록한 내용을 짧게 공유하는 스터디입니다.

매주 자신의 주제에 대해 약 10분 내외로 발표하고 자유롭게 질문을 나눕니다.
발표는 블로그 글을 바탕으로 진행하며, 매주 발표 전 워크플로우 폼을 작성하거나, 수동으로 [템플릿](TEMPLATE.md)에 맞춰 본인의 디렉토리에 업로드합니다.

## How We Share

1. 자유롭게 발표 주제를 선택합니다.
2. 주제는 선정 후 다른 참여자들의 이해도를 높일 수 있도록 사전에 공유합니다.
3. 공부한 내용을 개인 블로그에 작성합니다.
4. 워크플로우 입력 폼으로 발표 정보를 등록합니다.
	-  또는 자신의 디렉터리에 발표 정보를 담은 Markdown 파일을 추가합니다.
5. 변경사항이 기본 브랜치에 반영되면 발표 기록이 자동으로 갱신됩니다.
6. 블로그 글을 바탕으로 10분 내외로 발표합니다.

## Register a Talk

GitHub Actions 입력 폼으로 발표 정보를 등록할 수 있습니다.

1. 발표에 사용할 글을 개인 블로그에 작성합니다.
2. 저장소의 **Actions** 탭에서 `Update talks`를 선택합니다.
3. `Run workflow`를 누르고 폼을 작성합니다.
4. 회차, 발표 날짜, 발표 주제, 블로그 글 URL을 입력합니다.
5. `Run workflow`를 눌러 실행합니다.
6. 완료되면 `talks/본인의 GitHub ID/` 디렉토리에 발표 파일이 생성되고 아래의 Talks 표가 갱신됩니다.

발표자는 폼을 실행한 GitHub 계정으로 식별합니다. 
폼은 신규 발표 등록 전용이며, 같은 발표자의 같은 회차는 중복 등록할 수 없습니다.
기존 발표를 수정하거나 삭제하려면 해당 Markdown 파일을 변경한 뒤 브랜치에 반영합니다.
이후 Talks 표도 자동으로 다시 생성됩니다.

Markdown 파일을 직접 추가하는 방식도 사용 가능합니다. [TEMPLATE.md](TEMPLATE.md)를 복사하여 `talks/본인의 GitHub ID/` 디렉토리에 저장한 뒤 `main` 브랜치에 반영합니다.
